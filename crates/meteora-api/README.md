# Meteora API Rust Client

[![crates.io version](https://img.shields.io/crates/v/meteora-api)](https://crates.io/crates/meteora-api)

## Installation

Add the crate to an application that provides an async runtime, such as Tokio:

```bash
cargo add meteora-api
cargo add tokio --features macros,rt-multi-thread
```

## Usage

Each Meteora product has an independent client and production base URL. Create
only the client for the product you need; all generated methods are async and
support fluent builders for optional parameters.

```rust
use meteora_api::create_dlmm_api;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let dlmm = create_dlmm_api();
    let pools = dlmm.get_pools_builder().send().await?;

    println!("{pools:#?}");
    Ok(())
}
```

The crate exports `create_dlmm_api`, `create_damm_v1_api`,
`create_damm_v2_api`, `create_dynamic_vault_api`, and
`create_stake2earn_api`. Override an API host with the generated client's
`with_base_url` method when targeting a development environment.

## Development

This crate is part of the repository's root Cargo workspace. Its checked-in
clients are generated by `openapi-to-rust` from the OpenAPI specs in
`openapi/`.

Install the generator once:

```bash
cargo install --locked openapi-to-rust
```

Then, from the repository root:

```bash
# Regenerate all Rust clients.
just generate

# Format, type-check, or compile the Rust workspace.
just fmt
just check
just build
```

## Releases

Rust changesets are managed by `cargo-changeset` and stored under
`.changeset/changesets/`. They generate this crate's `CHANGELOG.md` and tags in
the `meteora-api-rs@v*` format.

```bash
just changeset
just release
```
